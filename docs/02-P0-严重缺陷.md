# P0 严重缺陷

审查基准 `788c173`（2026-11-19）。当前 1 条。旧 P0-01 的引用计数推导有误，纹理加载路径的泄漏已移入 P2-43。

## P0-03 交换链重建失败后可能解引用空指针

`Engine/Source/Runtime/RenderRT/Private/RenderRTImpl.cpp:80-106` 的 `UpdateRenderTargetView` 解绑当前 RTV 后，直接调用 `MainRenderTarget.Get()->Release()`。此时智能指针仍保存旧地址。随后函数忽略 `ResizeBuffers`、`GetBuffer`、`CreateRenderTargetView` 的返回值。

可以直接从控制流确定的崩溃条件是 `GetBuffer` 失败且输出仍为空。函数随后无条件执行 `pBackBuffer->Release()`。单次 `ResizeBuffers` 失败本身不足以判定取回旧缓冲区也会失败。若重建没有可用 RTV，`SetRenderTarget` 还会把空视图传给 `ClearRenderTargetView`。

修复时用 `MainRenderTarget.Reset()` 释放所有权，用局部 `ComPtr` 接收后备缓冲区和新 RTV，逐步检查 HRESULT。仅在重建成功后恢复绘制并提交视口尺寸。验收时分别覆盖调整尺寸失败、取缓冲区失败、创建视图失败，检查下一帧是否跳过无效目标。
